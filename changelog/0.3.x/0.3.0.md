# 0.3.0 — 2026-10-29

## Added

- **`wikipedia_get_references`** lists an article's footnotes a page at a time, each with its text, links, and DOIs ([#72](https://github.com/cyanheads/wikipedia-mcp-server/issues/72)). `{{rp}}` page numbers keep their spacing, and links the parser rewrote from http to https read as https.
- **`wikipedia-guide` agent skill** served at `skill://wikipedia-guide/SKILL.md` through `createApp({ skills })`; `skills/` ships in the package and the Docker image.

## Changed

- **URLs in `content[]`** render as CommonMark links (`[host](<url>)`) and the summary thumbnail as an image, on every tool, so `*`, `_`, and parentheses in a URL no longer break the rendering ([#78](https://github.com/cyanheads/wikipedia-mcp-server/issues/78)).
- **`revision_unavailable`** tells the caller to omit the cursor when the pinned revision is gone or hidden, and to retry when the failure is transient.

## Fixed

- **Hidden CS1 citation maintenance and error messages** no longer appear in article text ([#75](https://github.com/cyanheads/wikipedia-mcp-server/issues/75)).
- **Formula extraction** runs in time linear in the article's size.
