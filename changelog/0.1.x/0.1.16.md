# 0.1.16 — 2026-07-29

## Fixed

- **`wikipedia_get_article`** section reads drop `{{Side box}}`-family templates — `{{Library resources box}}`, `{{Sister project links}}`, `{{Portal}}` — and `role="navigation"` bars (`{{Portal bar}}`, `{{Sister bar}}`), which the `metadata`-class check previously matched only on `<table>` and so let through as prose when emitted as a `<div>`. `{{Spoken Wikipedia}}` is dropped too, on its own `spoken-wikipedia` class, since it carries neither marker. A pointer such as French Wikipedia's `{{Article détaillé}}` also carries `metadata` but on neither a box container nor a `role="navigation"` bar, so it is kept ([#34](https://github.com/cyanheads/wikipedia-mcp-server/issues/34)).
