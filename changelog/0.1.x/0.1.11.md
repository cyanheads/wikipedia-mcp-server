# 0.1.11 — 2026-07-16

## Added

- **`wikipedia_get_languages`** output gains `edition_code` — the Wikipedia subdomain that actually serves each language edition, derived from the article URL host. Pass this (not `language_code`, the raw MediaWiki code) as the `language` parameter to other tools; the two can diverge (e.g. code `gsw` lives on subdomain `als`) ([#17](https://github.com/cyanheads/wikipedia-mcp-server/issues/17)).

## Changed

- **`devcheck`**'s outdated-dependency check now recognizes bun's `minimumReleaseAge` supply-chain guard — a package bun is deliberately holding back (marked `*`) no longer reads as an unexpected finding.
- **`bunfig.toml`** added — blocks installing package versions published less than 3 days ago, excluding `@cyanheads/mcp-ts-core` (adopted same-day).
- **`Dockerfile`** — base image bumped to `oven/bun:1.3.14`; BuildKit cache mounts added to all three `bun install` layers; build stage now installs with `--ignore-scripts`.
- **`.gitattributes`**, **`.github/SECURITY.md`**, **`.github/FUNDING.yml`** added.
- **Vendored skills** (12) synced to mcp-ts-core 0.10.14.
- **`package.json`** `author` normalized to `Casey Hand <casey@caseyjhand.com> (https://caseyjhand.com)`.

## Fixed

- **`WIKIPEDIA_BASE_URL`** is now wired into request construction as an optional single-instance override, previously parsed and documented but never reaching `WikipediaService`. Unset (default): unchanged, composes `https://<language>.wikipedia.org` per call. Set: every request routes at that fixed host verbatim, `language` no longer selects the host, and Wikipedia-edition validation is skipped ([#16](https://github.com/cyanheads/wikipedia-mcp-server/issues/16)).
- **`invalid_language` errors** for a structurally-valid but nonexistent Wikipedia edition (e.g. `language: "zz"`) now populate `data.reason: 'invalid_language'` on all six tools, moved from `buildBaseUrl()`'s untyped `validationError()` into each handler via the new exported `isUnknownEdition()` ([#18](https://github.com/cyanheads/wikipedia-mcp-server/issues/18)).
