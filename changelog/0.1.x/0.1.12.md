# 0.1.12 — 2026-07-16

## Fixed

- **`wikipedia_get_article`** and **`wikipedia_get_sections`** now pass `redirects: 'true'` to the Action API, matching `wikipedia_get_summary`'s existing behavior — an alias title (e.g. "NYC") resolves to the target article instead of an empty redirect stub. `wikipedia_get_sections` output `title` now carries the resolved title rather than the raw input alias ([#19](https://github.com/cyanheads/wikipedia-mcp-server/issues/19)).
- **`wikipedia_get_sections`** migrated off the deprecated `prop=sections` Action API parameter to `prop=tocdata` — output shape is unchanged ([#25](https://github.com/cyanheads/wikipedia-mcp-server/issues/25)).
- **Blank/whitespace-only titles** are now rejected with a typed `not_found` error via a shared `isBlankTitle()` guard, checked before any network call, across `wikipedia_get_summary`, `wikipedia_get_article`, `wikipedia_get_sections`, and `wikipedia_get_languages`. Also closes a `wikipedia_get_summary` path that leaked a raw 403 error carrying the fetch URL ([#20](https://github.com/cyanheads/wikipedia-mcp-server/issues/20)).
