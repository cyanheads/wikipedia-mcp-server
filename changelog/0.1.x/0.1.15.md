# 0.1.15 — 2026-07-29

## Fixed

- **`wikipedia_get_article`** section-targeted reads (`section_index`) now render the Action API's `action=parse&prop=text` HTML for that section instead of stripping raw `prop=wikitext` through `wtf_wikipedia`. Subsection headings render inline above their own body instead of hoisted into one block at the top, and inline templates (`{{code}}`, `{{mono}}`) survive intact instead of stripping to empty strings ([#28](https://github.com/cyanheads/wikipedia-mcp-server/issues/28)).
- **`wikipedia_get_article`** section reads keep `<table role="presentation">` elements — the parser's own marker for layout-only tables such as `{{col-begin}}` multi-column lists and succession boxes — instead of dropping them along with genuine data tables. `tr`/`td`/`th` are now block boundaries so a layout table's cells render as separate lines instead of concatenating. Maintenance banners (`role="presentation"` plus `class="metadata"`, the ambox family) are still dropped ([#32](https://github.com/cyanheads/wikipedia-mcp-server/issues/32)).
- **`wikipedia_get_article`** section reads drop elements hidden by an inline `style="display:none"` regardless of tag or class, removing the Math extension's screen-reader MathML twin — previously every formula rendered twice — and `{{calculator}}` gadget chrome (button labels, widget state). The formula itself is recovered from `img.mwe-math-fallback-image-*`'s `alt` attribute before the hidden twin is dropped, so no math is lost ([#33](https://github.com/cyanheads/wikipedia-mcp-server/issues/33)).

## Dependencies

- `wtf_wikipedia` `^10.4.2` removed — section reads no longer strip raw wikitext.
