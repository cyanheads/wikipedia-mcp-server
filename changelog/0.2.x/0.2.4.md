# 0.2.4 — 2026-09-22

## Added

- **`wikipedia_get_article`** returns `url` and `revision_id` on every read, and `last_modified` on full reads, for citing the exact text read — `?oldid=<revision_id>` is a permanent link ([#53](https://github.com/cyanheads/wikipedia-mcp-server/issues/53)).
- **`wikipedia_get_article`** section reads render data tables as pipe rows and infoboxes as `label: value` lines instead of dropping them; a table over 40,000 rendered bytes leaves a `[table omitted: N rows]` marker ([#50](https://github.com/cyanheads/wikipedia-mcp-server/issues/50)).

## Fixed

- **`wikipedia_get_article`**, **`wikipedia_get_summary`** superscripts and subscripts (`10²³`, `H₂O`) no longer flatten into the digits beside them ([#48](https://github.com/cyanheads/wikipedia-mcp-server/issues/48)).
- **`wikipedia_get_article`** code samples in `content[]` are now fenced and unescaped instead of markdown-escaped ([#49](https://github.com/cyanheads/wikipedia-mcp-server/issues/49)).
- **`wikipedia_get_article`** section reads no longer carry editor-only preview warnings ([#57](https://github.com/cyanheads/wikipedia-mcp-server/issues/57)).
