# 0.2.0 — 2026-09-17

## Changed

- **`wikipedia_search`** renamed to **`wikipedia_search_articles`** (#37). Inputs, outputs, and behavior are unchanged — callers switch the tool name; `tools/list` no longer advertises `wikipedia_search`.
- **`@cyanheads/mcp-ts-core`** `^0.12.3` → `^0.13.2`. The dev skills directory moves `skills/` → `framework-skills/` so a Claude Code or Codex plugin install of this server doesn't inherit them; log rate-limiting (`MCP_LOG_RATE_LIMIT_THRESHOLD`/`MCP_LOG_RATE_LIMIT_WINDOW_MS`) is newly configurable.
- **`sessionMode: 'stateless'`** now declared on `createApp()` in `src/index.ts`, rather than left solely to the `MCP_SESSION_MODE` deployment variable.

## Fixed

- **`wikipedia_get_sections`** titles are now rendered to plain text from `prop=tocdata`'s `line` field (#36): `<span>` wrappers stripped, HTML entities decoded once, and no-break spaces folded to ordinary ones, so `sections[].title` matches `wikipedia_get_article`'s `section_title` for the same `section_index`.
