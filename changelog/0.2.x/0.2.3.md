# 0.2.3 — 2026-09-22

## Added

- **`wikipedia_search_articles`** results carry a short `description` and Wikidata `wikibase_item` per hit, via a best-effort follow-up lookup, and gain an optional `suggestion` enrichment field naming Wikipedia's spelling correction for the query ([#51](https://github.com/cyanheads/wikipedia-mcp-server/issues/51), [#52](https://github.com/cyanheads/wikipedia-mcp-server/issues/52)).
- **`wikipedia_search_nearby`** results carry a short `description` and Wikidata `wikibase_item` per hit ([#52](https://github.com/cyanheads/wikipedia-mcp-server/issues/52)).

## Fixed

- **`wikipedia_search_nearby`**'s cap notice no longer advises raising `limit` once at the 500 ceiling, and its tool description now names the article's own GeoData coordinate tag rather than Wikidata's ([#54](https://github.com/cyanheads/wikipedia-mcp-server/issues/54)).
