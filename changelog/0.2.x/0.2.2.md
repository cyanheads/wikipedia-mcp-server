# 0.2.2 — 2026-09-17

## Added

- **`wikipedia_get_summary`** returns `latitude`/`longitude` for a geotagged article — chainable straight into `wikipedia_search_nearby` — plus `url`, `revision_id`, and `last_modified` from the REST summary (#44).
- **`wikipedia_get_languages`** gains an `editions` filter to narrow the language list to requested codes; unmatched codes come back in `missing`, and `total_languages` stays the unfiltered count (#45).

## Changed

- `content[]` text from every tool now carries CommonMark backslash escapes on markdown-active characters in upstream-sourced strings, including the overflow outline's own bullets in `wikipedia_get_article`; `structuredContent` is unchanged (#43).

## Security

- Upstream text (article content, extracts, snippets, titles) rendered unescaped into `content[]`'s markdown, so literal HTML tags and markdown syntax from Wikipedia prose were reinterpreted by markdown-rendering clients; every tool's `format()` now escapes it via a new `escape-markdown` helper (#43).
