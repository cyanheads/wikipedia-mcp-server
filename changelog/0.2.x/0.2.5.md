# 0.2.5 — 2026-09-22

## Fixed

- **`apiGet`** now classifies `ratelimited`, `readonly`, and CirrusSearch's too-busy codes inside the retry ladder instead of after it returns, so every Action API call site gets the same backoff a 503 gets; an upstream `Retry-After` on the 200 response is honored over blind exponential backoff ([#55](https://github.com/cyanheads/wikipedia-mcp-server/issues/55)).
- Each request's whole retry ladder — every attempt, every backoff, every honored `Retry-After` — is now bounded at 30s, and a caller's cancellation ends a backoff as well as a request in flight; an exhausted budget fails with a `Timeout` error rather than outlasting a client's own request timeout.
