# 0.2.7 — 2026-10-24

## Changed

- **Article and section redirects** expose the original alias and target fragment, with a verified section index in section lists; explicit section reads take precedence ([#62](https://github.com/cyanheads/wikipedia-mcp-server/issues/62)).
- **Overflow outlines** include verified `section_index` values for direct reads, preserving unindexed entries when headings are ambiguous or TOC verification is unavailable ([#63](https://github.com/cyanheads/wikipedia-mcp-server/issues/63)).
- **Article search** documents CirrusSearch operators and accepts relevance, last-edit, creation-time, incoming-link and natural-title ordering, echoing the effective sort ([#64](https://github.com/cyanheads/wikipedia-mcp-server/issues/64)).
- **Search limits** above 50 articles or 500 nearby results are clamped with requested/applied limits and guidance; nearby coordinate bounds are advertised in the input schema ([#65](https://github.com/cyanheads/wikipedia-mcp-server/issues/65)).
- **Runtime and maintenance guidance** use Bun 1.4.2 → 1.4.4, refreshed framework references and a gated release review.

## Fixed

- **Empty summaries** return existing-page metadata and an empty extract with lead-read guidance; empty descriptions are omitted ([#61](https://github.com/cyanheads/wikipedia-mcp-server/issues/61)).
