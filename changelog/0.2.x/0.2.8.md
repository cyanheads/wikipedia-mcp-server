# 0.2.8 — 2026-10-24

## Changed

- **Table reads** accept `table_index` and `cursor` to retrieve omitted rows in revision-pinned pages within 40,000 UTF-8 bytes on both surfaces; an indivisible oversized row or first-page caption/header is returned alone with `oversized_row: true` ([#67](https://github.com/cyanheads/wikipedia-mcp-server/issues/67)).

## Fixed

- **Phylogenetic trees** retain branch hierarchy, sibling order and unnamed forks as fenced text; unparseable trees leave an explicit marker ([#68](https://github.com/cyanheads/wikipedia-mcp-server/issues/68)).
- **Search regex refusals** return `invalid_query`, the upstream code and corrective guidance for invalid or over-complex expressions ([#69](https://github.com/cyanheads/wikipedia-mcp-server/issues/69)).
- **Section errors** preserve `invalid_title` and its title recovery instead of relabeling every validation failure as `invalid_section` ([#70](https://github.com/cyanheads/wikipedia-mcp-server/issues/70)).
- **Scientific headings** preserve scripts and formulas consistently across section lists, article reads and verified outline indices; normalization work stays bounded ([#71](https://github.com/cyanheads/wikipedia-mcp-server/issues/71)).

## Dependencies

- `@biomejs/biome` ^2.5.15 → ^2.6.2.
